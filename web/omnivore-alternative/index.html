The Sustainable Omnivore Alternative

A Read-It-Later App That Can Never Shut Down

Omnivore was beloved, but centralized cloud servers inevitably incur hosting bills and acquisition risks. Zen Reader removes the server entirely to create a permanent, local reading sanctuary.

The Lesson from Omnivore's Sunset

In late 2024, Omnivore announced the sunset of its hosted cloud service. Thousands of readers who trusted the platform had to scramble to export their data before servers were shut down.

When an app uses a cloud database to store public web articles, every active user increases server hosting costs. When funding ends, the service dies.

The Zen Reader solution: By storing articles strictly inside your browser’s IndexedDB sandbox, there is zero cloud overhead, zero API latency, and 100% data ownership.

FAQ for Omnivore Migrators

Can I customize font size and color palette?
Yes. Zen Reader includes three custom reading themes (Paper, Sepia, and Night) along with adjustable font sizing and serif typography designed for extended reading comfort.
Is Zen Reader open source?
Yes, 100% open source under the permissive MIT license. You can inspect every line of code, fork the repository, or build the extension from scratch on GitHub.
